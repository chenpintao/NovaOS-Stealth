注入与挂载

平台每次必载的 manifest 文件前缀，通常无需改。
iframe 使用该域名加载 Tzy OS（与专栏页跨域，存储/DOM 完全隔离），须在 DNS 劫持列表内。
形如 /__nova__/，斜杠包裹；改掉即换“入口暗号地址”。
「本地文件」应用的访问边界，如 D:/；留空则默认用户主目录，越界访问一律拒绝。
开启后劫持期间访问一次即可把注入器与 Tzy OS 全部写入浏览器长期缓存；之后断开 DNS 劫持，OS 仍能唤起使用。业务数据接口不会被缓存。热点模式（模式1）默认开启，局域网模式（模式2）默认关闭，可在此手动打开。

隐蔽唤起方式

① 键盘热键（电脑端）

单个按键，如 y、o、F2。

② 角落连点（手机端主入口）

范围 1–9 次。
范围 8–64 px，越小越不影响页面正常点击。
范围 300–5000 ms，全部连点需在此时间内完成。

③ 网址暗参（收藏夹直达）

专栏网址末尾追加 &_o=1 打开即自动唤起。

④ 搜索框口令（手机推荐）

在专栏页任意搜索框/输入框中输入口令即唤起（输入后自动清空，不会真的搜索）；桌面端不聚焦输入框直接敲口令同样有效。

服务与 DNS

网页浏览器（内置代理）

网页浏览器出站走本机内置正向代理（HTTP 转发 + HTTPS CONNECT 隧道），仅监听 127.0.0.1，不对外暴露。修改端口后需重启服务生效。
热点模式（模式1）：平板连电脑热点，自动劫持下列域名到本机。局域网模式（模式2）：把平板 Wi-Fi 的 DNS 手动设为电脑局域网 IP，照常打开「在线专栏」即可，无需输网址。
非劫持域名全部转发上游，不影响其他网站。
